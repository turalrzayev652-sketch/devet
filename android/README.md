# android

Android app: Kotlin, Jetpack Compose, minSdk 26, `supabase-kt`.

Created in T41A. String resources are generated by `/tools/i18n` — do not edit by hand.

## Build

```
# JDK 17 (Gradle 8.14 does not run on JDK 25, which newer Android Studio bundles)
./gradlew test assembleDebug
```

Supabase settings come from `local.properties` (gitignored) or environment variables:

```
SUPABASE_URL=https://<project>.supabase.co
SUPABASE_ANON_KEY=<anon key>          # anon only — never service_role
PUBLIC_BASE_URL=https://<guest domain>
```

Without them the app still builds and starts; network features stay disabled (`SupabaseConfig.isConfigured`).

**Demo mode (debug builds only):** add `DEVET_DEMO=true` to `local.properties` to start signed in with in-memory events
(`src/debug/.../di/DemoModule.kt`). Used to try screens on an emulator before a Supabase project exists; release builds
have no demo code (`src/release` stub, `BuildConfig.DEMO = false`).

## Structure

- `ui/theme/` — design tokens from `/spec/design.md` (colours, type, spacing, radius). `DesignTokensTest` fails if they drift from the spec.
- `ui/navigation/` — type-safe Navigation Compose routes; the root screen follows the session (`rootFor`).
- `data/events/` — screens [2] and [3]: `EventRepository` (list with roles and mini stats, create, PATCH with changed columns only, owner-only delete), `EventRules` (validation, Baku time, 7-day archive), `MapsLink` (map link → coordinates, `spec/test-vectors/maps.json`), local "Arxivlə" (`ArchiveStore`). `ui/events/` — list, 6-step wizard, edit page.
- `data/guests/` — screen [7]: `Phones` (E.164, `spec/test-vectors/phones.json`), `ExcelRules` (`excel.json`: header aliases, row rules, duplicate warnings), `XlsxReader` (own minimal .xlsx reader — zip + SAX, no Apache POI), `DisplayNames` (salutation forms from `spec/i18n/invite.json` for the preview), `GuestRepository` (one batch insert; limit refusal → `AddResult.LimitExceeded`). `ui/guests/` — add guests (manual · contacts · Excel).
- Screen [6]: `GuestListRepository` (list, `event_guest_limit`, PATCH changed columns, bulk `table_no`/`side` with `id=in.(…)`, owner-only delete), `GuestListViewModel` (filters with counts, search by folded name or phone digits, limit ring levels, edit sheet, multi-select). `EventScreen` hosts the in-event bottom navigation (Guests · Send · Statistics · More; the last three come with T48/T49/12a).
- `excel.json`, `phones.json` and `invite.json` are copied from `/spec` into `assets/spec/` on every build (`copySpecAssets` in `app/build.gradle.kts`) — never edit copies. `assets/sample/guests-sample.xlsx` is the "download a sample" file.
- Contacts use the system phone picker (`ACTION_PICK` on phone numbers): no contacts permission; one contact per pick, "Another contact" adds more.
- `data/auth/` — Supabase Auth (sign in/up, confirmation resend, password reset, PKCE code exchange), errors mapped to `AuthError` (spec/api.md §0.2). `ui/auth/` — screens of [1]; `ui/settings/` — [12b]; `ui/events/` — [2] shell until T43.
- E-mail links: `az.devet.app://auth/callback` (sign-up confirmation) and `az.devet.app://auth/reset-password` (recovery), handled in `MainActivity` → `AppViewModel`. Both must be in Supabase → Authentication → URL Configuration → Redirect URLs (`az.devet.app://auth/**`).
- `di/` — Koin module; `data/` — Supabase client.
- `res/values*/strings.xml` — generated (az default, ru, en, tr). The app follows the system language; per-app language works through `locales_config.xml`.

## Dependencies and why

| Library | Why |
|---|---|
| Compose BOM, Material 3, activity-compose | UI toolkit required by CLAUDE.md |
| navigation-compose + kotlinx-serialization | screen flow with type-safe routes (spec/screens.md) |
| Koin | lightweight DI without annotation processing (keeps build fast, no kapt/ksp) |
| supabase-kt (auth, postgrest, storage, functions) + Ktor OkHttp engine | backend client required by CLAUDE.md; Ktor is its HTTP layer |
| appcompat | per-app language from Settings (`AppCompatDelegate.setApplicationLocales`) on Android 8–12 too |
| kotlinx-coroutines-test, ktor-client-mock (tests only) | view model tests; the real supabase-kt client against canned Auth answers (`SupabaseAuthRepositoryTest`) |
| Inter, Noto Serif Display (OFL, `licenses/`) | fonts from spec/design.md; bundled so Azerbaijani letters (ə, ğ, ı, ö, ş, ü, ç) render the same on every device |
